# my-c-compiler

Geminiを相棒にして、RustでC言語の `Hello, World` が動くコンパイラを自作するプロジェクトです。

## 🚀 プロジェクトのコンセプト

「C言語」誕生のストーリーを調べる中で、非常に興味深いエピソードを発見しました。
これがきっかけとなり、C言語を本格的に学習するため、バイブルである名著『プログラミング言語C 第2版（The C Programming Language, Second Edition）』を購入しました。

本書の冒頭には、世界一有名と言っても過言ではない `hello, world` のプログラムが登場します。

```c
#include <stdio.h>

main()
{
    printf("hello, world\n");
}
```

このコードを初めて見たとき、私の頭の中は「？？？」でいっぱいになりました。
「えっ、これで本当に動くの？」
「そもそも、最初の『＃』って一体どんな働きをしているの？」

右も左もわからない状態でしたが、調べていくうちに面白い歴史を知りました。
C言語が誕生する以前のシステム開発は、すべてアセンブリ言語で行われていたそうです。
そうであるならば、最終的にアセンブリ言語さえ生成できれば、コンピュータは思い通りに動かせるということになります。
つまりC言語とは、「人間が読みやすいコードからアセンブリ言語を自動生成するためのシステム」であるとも言えるわけです。

この本質に気づいたとき、新たなワクワクが生まれました。
「だったら、この `hello, world` の文字の羅列が、具体的にどうやってアセンブリ言語へと結びつき、変換されていくのかを自分の手で確かめてみたい」と。

この気づきを起点に、C言語のコードをアセンブリ言語へと変換する自作コンパイラの開発を決意しました。
開発言語には、現代の低レイヤ開発で強力なパワーを発揮する **Rust** を選択しています。これが本プロジェクトの最終目標です。

本プロジェクトでは、**「AI（Gemini）をフル活用してコンパイラを構築し、生成されたコードを1行ずつ深く理解して自分の血肉にする」**というアプローチを採用しています。

ネットで散らばった情報を検索する代わりに、AIに自分のコードの文脈に沿った解説や要約を出力してもらい、それを優秀なナビゲーターとしてステップバイステップでじっくり学習を進めていきます。

最初は何もわからなくても、自作コンパイラを作り進める中で、パズルのピースがはまるように仕組みが身についていくはず。
*「あ、あの『＃』はこういう意味だったんだ！」*と気がつきながら進むロードムービーのような開発記です。
そして最終的に、自分の作ったコンパイラから `hello, world` が出力されて「バンザーイ！」と叫ぶその日まで、この冒険を楽しんでいきます。
の冒険を楽しんでいきます。

## 🛠 現在出力できるアセンブリの例

数式（例: `(1 + 2) * 4 / 3`）から、以下のようなスタックマシンベースのアセンブリを出力し、実行ファイル化まで達成しています。

```assembly
.intel_syntax noprefix
	.globl main
main:
	push 1
	push 2
	pop rdi
	pop rax
	add rax, rdi
	push rax
	push 4
	pop rdi
	pop rax
	imul rax, rdi
	push rax
	push 3
	pop rdi
	pop rax
	cqo
	idiv rdi
	push rax
	pop rax
	ret
```
